# Cleo's Creators

Motivation:
Many students have trouble with motivation and maintaining focus. 

Oftentimes it is rather daunting when we think about the projects and tasks because we see the big, complex tasks we need to complete. This can cause some to be demoralized before they even start work and can make it even harder to build up the motivation to start.

Another struggle for students is staying focused in a world full of distractions. From gaming to social media there are so many things that can distract you from your work. Students find it very hard to resist the temptations of a distraction and feel as though we cannot rely on our own self-discipline.
